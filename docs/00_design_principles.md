# C. elegans 工程复刻 — 设计原则与反作弊公约

> 版本: 0.1.0 | 日期: 2026-02-10
> 地位: **第一约束** — 所有设计决策和代码审查必须首先满足本文档的原则
> 核心命题: 行为 = 连接组 × 生物物理 × 环境交互，代码只提供结构和物理定律

---

## 一、核心哲学

### 本项目不是什么

```
❌ 行为脚本:    if see_food → turn_toward(food)
❌ 状态机:      STATE_FORWARD → detect_obstacle → STATE_REVERSE
❌ 控制论模型:   PID 控制器跟踪化学梯度
❌ 神经网络近似: 用 ANN 拟合输入输出映射

✅ 本项目: 302 个生物物理神经元 + 真实连接组 + 物理身体 → 行为涌现
```

### 本项目是什么

一个**生物物理仿真平台**：

- 代码提供「物理定律」— 离子通道动力学、突触传导方程、肌肉力学
- 结构来自「解剖学数据」— 连接组、神经元类型、递质分配
- 行为从「网络动力学 × 身体 × 环境」中涌现 — 不是从 if-else 逻辑中推导

### 与 agi3 (哺乳动物大脑) 的关键区别

| 维度 | agi3 (人脑) | agi4 (线虫) |
|------|-----------|-----------|
| 连接组 | 未知，只有统计规律 | **完全已知** (EM 重建) |
| 突触权重 | 必须学习 | 部分可从 EM 数据估计 |
| 神经元数量 | ~10⁵ 模拟 | **302 全部模拟** |
| 信号编码 | 脉冲频率 | **分级电位** (大部分无 spike) |
| 行为复杂度 | 高级认知 | 感觉-运动行为 |
| 验证标准 | 认知任务表现 | **对标真实线虫行为数据** |

## 二、硬编码 vs 涌现 判定标准

### 2.1 允许硬编码的内容 (生物物理事实)

以下是从实验数据直接获取的物理/解剖学事实，**必须**写入代码：

| 类别 | 具体内容 | 数据来源 |
|------|---------|---------|
| **离子通道动力学** | Boltzmann 参数、时间常数、电导率 | Nicoletti 2019, Mellem 2008 |
| **膜方程** | C_m·dV/dt = ΣI, HH 框架 | Hodgkin & Huxley 1952 |
| **连接组拓扑** | 谁连谁、连接类型 (化学/电) | Cook 2019, Emmons 2024 |
| **突触计数** | EM 切面数 (面积代理) | WormAtlas, Cook 2019 |
| **递质类型** | 每个神经元释放什么递质 | Pereira 2015, Gendrel 2016 |
| **神经元类型** | 感觉/中间/运动分类 | WormAtlas |
| **身体形态** | 体长、肌肉数量、段数 | 解剖学测量 |
| **突触反转电位** | ACh/GABA/Glu 的 E_syn | 电生理实验 |
| **钙动力学方程** | 钙缓冲、衰减时间常数 | 钙成像数据 |
| **间隙连接对称性** | 电突触的欧姆耦合 | 生物物理定律 |

### 2.2 禁止硬编码的内容 (必须涌现)

以下内容**必须**从神经元网络动力学中产生，任何硬编码都视为「作弊」：

| 类别 | 作弊示例 | 正确的涌现方式 |
|------|---------|--------------|
| **运动模式** | `if forward_state: activate(B_class)` | AVB→DB/VB 突触驱动 + 本体感觉反馈产生蠕动波 |
| **趋化策略** | `if concentration_dropping: pirouette()` | ASE/AWC 感觉神经元响应→中间神经元处理→运动输出改变 |
| **转向决策** | `turn_angle = gradient_direction` | 头部感觉采样不对称 → RIA/SMD 差异激活 → 头部弯曲 |
| **速度调节** | `speed = f(food_distance)` | 感觉输入→中间神经元→AVB/AVA 活性变化→运动波能量变化 |
| **前进/后退切换** | `if touch_anterior: reverse()` | ALM→AVD→AVA 突触通路激活→A类运动神经元接管 |
| **觅食行为** | `search_pattern = levy_walk()` | 自发活动 + 感觉反馈 + 命令中间神经元噪声 → 运动轨迹涌现 |
| **适应/习惯化** | `response *= habituation_factor` | 突触短时程可塑性 (STP) 产生的递质耗竭 |
| **社交行为** | `if detect_pheromone: aggregate()` | 化学感觉→中间神经元→运动输出的神经通路 |

### 2.3 灰色地带处理原则

```
原则: 可以提供"驱动信号的物理来源"，但不能提供"行为的逻辑指令"

✅ 正确: AVB 接收来自上游中间神经元的突触输入 → 膜电位升高 → B 类运动神经元被驱动
         (因果链条: 突触电流 → 膜方程 → 递质释放 → 肌肉收缩)

❌ 错误: 检测到 AVB 应该激活 → 直接设置 AVB.membrane_potential = -30mV
         (跳过了物理过程)

✅ 正确: 头部振荡由 RMD/SMD 神经元内在电学特性 + 突触回路产生
         (生物物理机制)

⚠️ 临时允许: 头部振荡用正弦电流注入模拟 (Step 12 当前状态)
            → 这是"生物学占位符"，必须在后续步骤中替换为涌现机制
            → 在代码中标注: // PLACEHOLDER: replace with intrinsic oscillation circuit
            → 在 progress.md 中记录此技术债务

❌ 错误: 直接操纵身体段曲率/角度来产生运动
         (完全绕过了神经系统)
```

## 三、技术债务与占位符规则

在 MVP 阶段，某些涌现机制暂时无法实现，允许使用占位符，但必须：

### 3.1 占位符标注规范

```cpp
// PLACEHOLDER: [简述占位内容]
// BIOLOGY: [应该由什么生物学机制产生]
// REMOVE_BY: Step [N] 或 Phase [N]
// REF: [相关文献]

// 示例:
// PLACEHOLDER: Sinusoidal current injection to SMD head motor neurons
// BIOLOGY: Head oscillation should emerge from SMD-RMD reciprocal inhibition
//          + intrinsic membrane properties (CCA-1 T-type Ca²⁺ channels)
// REMOVE_BY: Phase 2 (multi-compartment neurons + complete head circuit)
// REF: Hendricks 2012, Shen 2016
```

### 3.2 占位符跟踪

每个占位符必须在 progress.md 的「技术债务」章节登记，包含：
- 占位符位置 (文件:行号)
- 对应的生物学机制
- 计划替换时间
- 优先级 (P0=阻断验证 / P1=影响行为精度 / P2=美化)

## 四、数据来源优先级

所有参数和结构必须有文献出处，优先级如下：

```
P0 (必须): 直接实验测量
   → 电生理记录 (膜电容、通道电导)
   → EM 连接组 (Cook 2019, Emmons 2024)
   → 钙成像 (Kato 2015, Nichols 2017)

P1 (推荐): 计算建模拟合
   → BAAIWorm 参数 (Nature Comput. Sci. 2024)
   → c302 框架参数
   → Nicoletti 2019 通道模型

P2 (可接受): 同源物种类比
   → 哺乳动物同源通道参数 (相同基因家族)
   → 其他线虫种的测量

P3 (临时): 合理估计
   → 在生物学合理范围内的初始猜测
   → 必须标注 // PARAM_SOURCE: estimated, needs calibration
   → 在后续步骤中通过优化/拟合替换

❌ 禁止: 凭空编造
   → 没有任何生物学依据的"魔法数字"
   → 为了让行为"看起来对"而调的参数
```

## 五、代码审查检验标准

### 检验 1: 因果链完整性测试

> **每个行为输出，能否追溯到一条完整的物理因果链？**

```
✅ 正确的因果链:
   环境化学浓度 → 感觉神经元膜电位变化 → 突触电流 → 中间神经元响应
   → 突触电流 → 运动神经元响应 → 递质释放 → 肌肉激活 → 身体运动

❌ 跳过环节:
   环境化学浓度 → [黑盒] → 身体运动
   感觉输入 → [if-else] → 运动输出
```

### 检验 2: 参数消融测试

> **把某个突触权重设为 0，行为变化是否符合生物学消融实验？**

- AVB 消融 → 不能前进 (Chalfie 1985) ✅
- AVA 消融 → 不能后退 ✅
- ASE 消融 → 趋化性丧失 ✅
- DD/VD 消融 → 背腹协调丧失 ✅
- **如果消融结果与文献不符 → 模型有 bug 或在作弊**

### 检验 3: 连接组忠实性测试

> **仿真中的连接是否与 EM 数据一致？**

- 不允许添加连接组中不存在的连接 (除非有明确的实验证据)
- 不允许删除连接组中存在的连接 (除非为简化且有说明)
- 权重比例应反映 EM 切面数的相对大小

### 检验 4: 无"上帝视角"测试

> **神经元是否只能通过自身的突触输入获取信息？**

```
❌ 作弊: neuron.receive(global_food_position)      // 神经元不可能知道全局信息
❌ 作弊: neuron.receive(body.total_curvature)       // 每个神经元只能感知局部
❌ 作弊: motor.output = desired_velocity             // 运动必须通过肌肉

✅ 正确: neuron.receive(synaptic_current_from_presynaptic_partners)
✅ 正确: sensory_neuron.transduce(local_concentration_at_nose_tip)
✅ 正确: proprioceptor.sense(local_body_curvature_at_segment_N)
```

### 检验 5: 时间尺度一致性测试

> **仿真中的时间常数是否与实验测量一致？**

- 膜时间常数 τ_m: ~10-50 ms (C. elegans 实测)
- EPSP 持续时间: ~10-100 ms
- 运动波周期: ~1-2 s (爬行), ~30 ms (游泳)
- 钙信号: τ_decay ~200-500 ms
- **不允许为了"让行为更快/更好"而修改时间常数**

## 六、验证标准: 对标真实线虫

### 6.1 行为对标 (Phase 1-2)

| 行为 | 实验数据 | 模型必须达到 |
|------|---------|------------|
| 前进爬行速度 | ~0.2 mm/s (琼脂板) | 同一数量级 |

## 七、开发流程约束

### 7.1 每个 Step 必须包含

1. **生物学依据**: 引用至少一篇文献支持实现方式
2. **因果链说明**: 从输入到输出的完整物理因果链
3. **占位符声明**: 明确标注哪些是占位符，计划何时替换
4. **验证指标**: 可量化的对标数据
5. **消融预测**: 移除该组件后预期的行为变化

### 7.2 禁止行为清单

```
□ 禁止: 在神经系统之外的代码中做行为决策
□ 禁止: 给神经元注入"语义信息" (如食物位置坐标)
□ 禁止: 使用 if-else 分支实现行为切换
□ 禁止: 直接操纵身体位置/角度/速度 (必须通过肌肉)
□ 禁止: 使用无生物学依据的"魔法数字"
□ 禁止: 为了结果好看而修改生物物理参数
□ 禁止: 添加连接组中不存在的突触连接 (除非有实验证据)
□ 禁止: 让信息跨越突触连接传播 (每个神经元只知道突触输入)
```
