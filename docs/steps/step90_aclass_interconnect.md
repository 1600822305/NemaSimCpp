# Step 90: A-class 后退运动回路互连完善

## 动机

Step 89 完成了 B-class (VB↔VB, DB↔DB) 本体感觉波传播和 AS 互连。
本步骤对称地完善 A-class 后退运动回路：添加 VA↔VA、DA↔DA 相邻间隙连接
支持后退波传播，DA↔AS 同步背侧激活，VA→DD 交叉抑制输入。

## 生物学基础

### A-class 内在振荡器
- **Gao 2018 eLife**: A-class MN 是非爆发式内在振荡器
  - 在移除所有前运动中间神经元后仍然产生节律性活动
  - 本体感觉耦合将相邻 A-class MN 相位锁定
  - 运动增强振荡强度和相位耦合
- **Gao 2018 eLife (review)**: 前运动中间神经元 (AVA) 双重调节 A-class
  - 间隙连接：共振放大振荡
  - 化学突触：调制振幅和频率

### 抗逆整流间隙连接
- **Liu 2017 Nat Commun**: AVA↔A-type MN 间隙连接具有抗逆整流特性
  - 电流优先从 A-MN 流向 AVA（逆向传导）
  - 类似脊椎动物 V2a 中间神经元的逆向招募

### VA→DD 交叉抑制
- **White 1986**: VA 化学突触输出到 DD 神经元
  - VA 兴奋 → DD 激活 → DD 抑制背侧 BWM → 背侧松弛
  - 后退运动中：VA 收缩腹侧 + 通过 DD 抑制背侧 = D/V 交替
