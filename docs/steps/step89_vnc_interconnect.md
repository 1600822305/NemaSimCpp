# Step 89: VNC 运动回路互连完善

## 动机

Step 84-88 完成了全部 69 个腹索运动神经元的定义，但神经元之间的互连仍不完整。
本步骤添加三类关键的运动回路内部连接，使 VNC 运动系统从"神经元完整"
升级为"回路完整"。

## 生物学基础

### 1. AS→VD 兴奋性连接（背侧偏转机制）
- **Tolstenkov 2018 eLife**: AS 去极化 → 兴奋重叠区域的 VD 神经元
  - VD 是 GABAergic → 抑制腹侧 BWM → 净背侧偏转
  - 这是 AS 产生背侧偏转的间接机制（直接 = 背侧肌肉兴奋）
  - AS 超极化 → VD 失活 → 腹侧去抑制 → 腹侧收缩
- **White 1986**: AS 化学突触输出主要到背侧肌肉和 VD 神经元
- **Olivares 2017**: 计算模型预测 AS→VD 对 D/V 协调至关重要

### 2. AS↔AVA 间隙连接（电反馈）
- **Tolstenkov 2018 eLife**: AS 光刺激 → AVA 中 18% ΔR/R Ca²⁺ 信号
  - 在 unc-7(e5) 突变体中消失 → UNC-7 innexin 介导
  - AS→AVB 信号不显著（间隙连接数量更少）
  - 功能意义：运动神经元向命令中间神经元提供反馈
  - 类似脊椎动物 V2a 中间神经元的逆向招募（Song 2016 zebrafish）
- **Liu 2017**: AVA↔A-type MN 间隙连接具有整流特性

### 3. DB↔DB 相邻间隙连接（背侧本体感觉波）
- **Wen 2012 Neuron**: B-type MN 通过本体感觉耦合传播弯曲波
  - VB↔VB 间隙连接已在 Step 87 添加（腹侧波）
  - DB↔DB 间隙连接提供对称的背侧波传播平台
- **Cook 2019**: DB(n)↔DB(n+1) 间隙连接存在于连接组中

### 2. AS↔AVA 间隙连接（11 条）

交替 L/R 模式（匹配化学突触模式）：
- 奇数 AS (01,03,05,07,09,11) ↔ AVAL（6 条）
- 偶数 AS (02,04,06,08,10) ↔ AVAR（5 条）
- 权重 1（UNC-7 innexin, Tolstenkov 2018）
