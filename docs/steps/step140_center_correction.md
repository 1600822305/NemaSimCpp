# Step 140: 局部中心修正 — 物理弯曲与转向恢复

## 动机

Step 139 实现了直接曲率驱动（phi-drive），通过神经元 D/V 差直接调整杆角度 phi，
成功产生了稳定的曲率振荡。但 phi 变化不会自动传导到杆中心位置 cx/cy，导致：

- **heading_rate ≈ 0 deg/s** — 虫体走直线，无法转向
- **CI = 0** — 趋化行为完全失效
- 本体感觉波传播正常，但物理轨迹是直线

根本原因：phi 和 cx/cy 解耦 — 曲率在角度空间振荡，但物理位置不弯曲。

## 尝试过的方案

### 1. 端点力偶（扭矩）方案 — 失败
- 在每个杆上施加 D/V 力偶（沿杆方向的力），创建扭矩
- **问题**：力偶创建纯扭矩（无中心净力），cx/cy 不动
- 头部曲率爆炸到 30 /mm 但中体为零

### 2. 中心法向力方案 — 失败
- 沿体轴法向推动杆中心，直接创建 cx/cy 弯曲
- **问题**：agar 介质拖曳力极大 (cn=1.3e-3 kg/s)，被动弹簧在大变形下
  锁死身体形状。肌肉力 (~5e-7 N) 远不够克服弹簧恢复力
- 身体弯一次就冻结，不随 SMD 振荡变化

### 3. phi-drive + 局部中心修正 — 成功 ✓

## 最终实现

### 三层架构

1. **Phi-drive**（曲率控制）
   - 神经元 D/V 差 → K_DRIVE × diff - K_RESTORE × dphi → 钳位 DPHI_MAX
   - K_DRIVE=0.15, K_RESTORE=5.0, DPHI_MAX=0.015
   - 直接调整杆角度，已验证稳定

2. **局部中心修正**（phi→cx/cy 一致性）
   - 每帧计算每对相邻杆的 phi 一致方向 vs 当前方向
   - 以 BLEND=0.15 逐步修正，无头到尾级联
   - 所有修正先计算再统一应用，防止帧内级联
   - 每杆修正幅度限制为 0.5×seg_len，防止 omega 期间 spike
   - 使 cx/cy 跟踪 phi 驱动的弯曲形状

3. **phi 曲率反馈**（切断正反馈环）
   - 本体感觉使用 phi 差曲率（非 cx/cy 位置曲率）
   - 中心修正不影响本体感觉 → 无正反馈放大
   - 关键发现：cx/cy 曲率 → 本体感觉 → phi → 更多 cx/cy 修正 = 爆炸

### 肌肉激活修复
- 移除 d/(d+v) 归一化（压缩 D/V 差到 ~1%）
- 改为 INPUT_SCALE=3.0 缩放（保持 D/V 比例，激活在 [0,1]）
- muscle_work 恢复到 0.2-0.3

## 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| K_DRIVE | 0.15 | phi 驱动强度 |
| K_RESTORE | 5.0 | 恢复到直线 |
| DPHI_MAX | 0.015 | 硬钳位 ~0.72 /mm |
| BLEND | 0.15 | 中心修正混合比 |
| MAX_ADJ | 0.5 | 每杆每帧最大修正 |
| INPUT_SCALE | 3.0 | 肌肉输入缩放 |
