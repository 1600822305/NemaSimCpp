# Step 88: AS 背侧单极运动神经元扩展 (AS7→11)

## 动机

现有模型仅有 AS01-07 共 7 个 AS 背侧单极运动神经元。真实 C. elegans
有 11 个 AS (AS1-AS11)，是腹索运动回路中最后一个未完整的兴奋性 MN 类型。
AS 扩展完成后，所有 75 个腹索运动神经元类型全部达到生物学完整数量。

## 生物学基础

### AS 运动神经元的独特功能
- **Tolstenkov 2018 eLife**: AS MN 的首次系统功能表征
  - AS 是唯一**不对称**的兴奋性 MN——仅投射背侧肌肉
  - AS 同时接收前进 (AVB) 和后退 (AVA) 命令中间神经元输入
  - AS 在前进和后退运动中均活跃（双模式）
  - AS→背侧 BWM (兴奋) + AS→VD (通过 VD 抑制腹侧)
  - AS↔AVA 间隙连接: 通过 UNC-7 提供电反馈给后退 PIN
  - AS 去极化 → 背侧偏转 → 模拟 weathervane 导航
  - AS 超极化 → 阻止身体波传播

### 在运动回路中的角色
- **Haspel & O'Donovan 2011**: 11 个 AS 分布在 6 个功能单元中
- **White 1986**: AS 无对称腹侧伙伴，提供背景背侧偏转
- **Chen 2006**: AS 在前进和后退运动中均活跃
- **Olivares 2017**: 计算模型预测 AS 在 D/V 协调中有重要作用

### AS 连接模式
- **AVA→AS**: 化学突触 (后退 PIN，交替 L/R)
- **AVB→AS**: 化学突触 (前进 PIN，交替 L/R)
- **DD⊣AS**: GABAergic 抑制 (腹侧相位期间)
- **DB↔AS**: 间隙连接 (同步背侧激活)
- **AS↔AVA**: 间隙连接 (电反馈至后退回路, UNC-7)
